# Third-party notices

The firmware links against STMicroelectronics STM32CubeF1 HAL and CMSIS supplied by PlatformIO. Their license notices remain in the installed framework package; this repository does not vendor those source files.

The [justmangoou/micromouse](https://github.com/justmangoou/micromouse) source is MIT licensed and was studied as a hardware/algorithm reference. No Micromouse application source file was copied into this repository. Pin assignments, measured calibration values, map coordinates and general engineering formulas are attributed in `docs/BASELINE_PARAMETERS.md` and `docs/REFERENCES.md`.

The group's `NhungProject` map and test history were used as project data. No third-party VL53L0X driver or planner module is included in the new project at this stage.
