# Locked V1 PCB qualification sequence

This sequence uses the locked `hybrid_planner_check_128k` image only after the Flash gate in `FLASH_128K_ACCEPTANCE.md` passes. Motor supply stays disconnected. No result here unlocks motor motion.

1. Measure PB0/STBY at boot, reset, watchdog reset and steady loop. PASS: LOW throughout the locked image; any HIGH pulse is FAIL. Check PB1 released at boot, held at boot, release and fresh press. PASS: held-at-boot never starts localization/mission; only release then press advances the software gate.
2. With the robot stationary at a surveyed START pose, watch `plannerPoseVerified`, `startLocalizationStatus`, `startLocalizationMeanErrorCm`, `startLocalizationCandidates`, `plannerStatus` and `one_run_link_storage.mission.state` over SWD. Run centered, left/right displaced, yaw displaced, one missing VL53 and ambiguous-return cases. PASS: only the independently surveyed, fresh, unambiguous case can verify pose; each invalid case keeps STBY LOW and route stopped. Zero or unreviewed configuration flags still block the current image by design.
3. Watch `startScanMaxCycles`, `plannerPollMaxCycles`, `controlLoopMaxCycles` and `SystemCoreClock`. Convert cycles to milliseconds using `cycles * 1000 / SystemCoreClock`; confirm DWT is counting. Capture per-case maxima for normal, delayed I2C, no-path and repeated-replan cases. The current maxima do not isolate A*, map update, local arc or ISR nesting; use SWD trace/breakpoints or additional scoped instrumentation before approving those budgets. Host timings are not STM32 timings.
4. Measure the minimum free stack during START scan, A*, replan, I2C error and worst interrupt nesting with an initialized stack watermark or equivalent debugger trace. Record the method, baseline address, lowest untouched address and margin to static data. The ELF's 4,096-byte spare is not this measurement. FAIL on canary damage, collision with static data, or unbounded growth.
5. Measure the PB0/STBY lease on the actual PCB with a scope/logic analyzer during a controlled stall, separately for drive (80 ms nominal) and brake (120 ms nominal). Record supply, trigger, actual cutoff and whether STBY stays LOW. The host lease test proves only software logic. A motor test requires a later, separately approved unlocked image and a physically secured vehicle; do not infer timing from the locked image alone.

Keep raw traces and the board identity with each result. PASS for this locked stage means all gates remain closed as specified, timing and stack have usable measured margins, and faults latch until reset. FAIL if stale VL53/gyro/encoder data, a planner fault, no path, or a held PB1 can authorize a route or leave STBY HIGH. Only then review calibration, surveyed map and GOAL rule. `hybrid_v1_staging` is a separate locked build target; it does not authorize motor motion.
